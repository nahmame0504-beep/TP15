# TP 15 : Expressions Lambda, Streams et Programmation Fonctionnelle en Java

---

##  Présentation du TP

Ce Travail Pratique (TP 15) couvre l'ensemble des concepts de la **programmation fonctionnelle** introduits en Java 8+. L'objectif est d'explorer la transition de la programmation impérative vers la programmation déclarative à travers 17 étapes d'apprentissage et 12 programmes exécutables.

---

##  Structure du Projet

```text
TP_Java_Lambdas/
├── README.md
└── src/
    └── com/
        └── example/
            └── tp/
                ├── CaptureLambda.java           # Étape 6  : Capture de variables locales & this
                ├── ComparateurCompose.java      # Étape 15 : Tri multi-critères avec Comparator
                ├── CompositionFonctions.java    # Étape 10 : Composition (andThen, compose, and, or)
                ├── CompteurTODO.java            # Étape 14 : Analyse d'arborescence & I/O avec Streams
                ├── ExceptionsLambda.java        # Étape 11 : Enveloppement des checked exceptions
                ├── FactorielleStream.java       # Étape 16 : Algorithmes fonctionnels avec IntStream
                ├── Memoizer.java                # Étape 17 : Mémoïsation générique avec ConcurrentHashMap
                ├── ReferencesMethodes.java      # Étape 7  : Syntaxe des références de méthodes (::)
                ├── StreamAvance.java            # Étape 9  : Groupement, réduction et statistiques Stream
                ├── StreamBasics.java            # Étape 8  : Opérations de base sur Streams (filter, map)
                ├── TriFunctionDemo.java         # Étape 13 : Interface fonctionnelle personnalisée (TriFunction)
                └── ValidationFormulaire.java    # Étape 12 : Pattern Builder de validation via Predicate
```
